panel (Phase 3).

**Start here → [`00-MASTER-PLAN.md`](./00-MASTER-PLAN.md)**

Rules for execution:
1. Work one file at a time, in the order given in the master plan.
2. Respect each file's "Depends on" line.
3. Finish the acceptance criteria of a plan before starting the next.
4. Update the status column in the master plan after each completed plan.
